# 게이트 3 — 실행속도 실측 보고서

## 판정

**합격.** iPhone 12 Pro에서 정확한 130×130(16,900조합) 병렬 탐색 평균은
**0.1463초**로, 분기 기준인 3초보다 충분히 짧다. 탐색 범위 축소나
백그라운드 처리 없이 다음 게이트로 진행할 수 있다.

## 측정 환경

- 기기: iPhone 12 Pro (`iPhone13,3`, `D53pAP`)
- OS: iOS 26.5.2
- 연결: USB, Developer Mode 활성
- 빌드: `Gate3Benchmark` 타깃 Release (`-O`, whole-module optimization)
- 물리 입력: 게이트 2 S4와 같은 `sm=2.5`, 경사 2°, 홀 3m/0°,
  속도 1~3m/s, 조준각 -13~13°
- 워밍업: 30×30 직렬·병렬 및 단일 궤적 각 1회, 평균에서 제외
- 궤적 기록: 비활성화

## 실측 결과

| 항목 | 반복 | 평균 |
|---|---:|---:|
| 단일 2,000스텝 풀런 | 20회 | 0.0002초 |
| 30×30 직렬 (900조합) | 5회 | 0.0305초 |
| 30×30 병렬 (900조합) | 5회 | 0.0086초 |
| 130×130 직렬 (16,900조합) | 3회 | 0.5652초 |
| 130×130 병렬 (16,900조합) | 3회 | **0.1463초** |

30×30에서는 매회 13개, 130×130에서는 매회 248개의 홀인 후보가
직렬·병렬에서 동일하게 반환되었다. 자동테스트에서도 후보의 값과 순서가
완전히 동일함을 검증했다.

## 격자·스텝 의미

게이트 2의 기존 Mathematica 호환 API는 N을 구간 수로 해석해 N+1개 점을
생성한다. 따라서 기존 API의 130은 131×131=17,161조합이다. 게이트 2 회귀
동작은 변경하지 않고, 게이트 3에는 각 축의 점 개수를 직접 받는 별도 API를
추가하여 문서 의미 그대로 30×30 및 130×130을 측정했다.

원본 적분 루프는 20/0.01 양 끝점을 포함해 2,001회 실행된다. 단일 성능
항목은 `timeFinal=19.99`, `dt=0.01`, `stopVelocity=0`, 먼 홀을 사용해 조기
종료 없는 정확한 2,000스텝을 측정했다.
