# 3D 그린 시뮬레이터 — 육안 사전점검 보고

게이트 5.5 전에 다중브랙 궤적을 3D로 확인하기 위한 정적 시뮬레이터.
`PuttPhysicsKit` 게이트 2~5 로직은 변경하지 않고, `GreenSimulator` 앱 타깃만 추가했다.

## 구현

| 항목 | 경로 |
|---|---|
| 앱 | `GreenSimulator/` (`GreenSimulatorApp`, `GreenSceneBuilder`, snapshot exporter) |
| 스킴 | `GreenSimulator` |
| 번들 ID | `com.trueputt.GreenSimulator` |
| 샘플 | `GreenSimulator/Resources/samples_all36/` (36개 `.grnh.gz`) |
| 물리 | `CandidateSelector` + `MultibreakPuttPhysics` + `GreenAligner` 재사용 |

### 사용법

1. Xcode에서 스킴 `GreenSimulator` 선택 후 시뮬레이터/기기 실행
2. 그린 선택 → **볼 놓기** / **홀 놓기**로 지형 탭
3. 자동 추천 카드에서 평지환산거리·보정·고도차·v0/β를 확인 후 **퍼팅**
4. 체크리스트 자동 PNG:  
   `xcrun simctl launch <UDID> com.trueputt.GreenSimulator --export-checklist`  
   → 앱 Documents/`green-sim-checklist/`

- `GreenSimulator` iOS Simulator Debug/Release: **성공** (2026-07-19)

## 추천 안내 (1순위 카드)

1순위만 한 화면에 카드로 상시 표시한다(2순위 비노출).

- 큰 글씨: **평지환산거리**
- 우측: **방향 인디케이터** — 볼→홀 기준선(0°) 대비 β만큼 회전한 조준 화살표(나침반형).
  실측(게이트 5.5) 시 폰을 볼 뒤에 놓고 조준선을 맞추는 데 쓰이므로 필수 요소다.
- 중간 글씨: 오르막/내리막 거리 보정, 순수 고도차
- 작은 글씨: v0, β 원시값, 예측 정지좌표, 오버런 오차
- 후보가 없으면 `후보 없음` 표시, 반경 완화 여부/후보 수는 상태 문구로 유지

평지환산거리는 후보의 v0를 게이트 2 `FlatPuttPhysics`의 평지(`slopeDegrees=0`)에
순방향으로 넣어 얻은 정지 이동거리다. `stopVelocity=0.01`, `timeFinal=20`,
`timeDelta=0.01` 기본값을 그대로 사용하며 별도 튜닝은 없다.

순수 고도차는 정렬된 지형에서 `H(홀) - H(볼)`로 계산한다. 게이트 2~5
물리·후보 선정 API와 구현은 변경하지 않았다.

## 지형 색 모드

하단 세그먼트로 **등고 / 경사** 전환(볼·홀·추천 상태 유지, 메시만 재도색).

- **등고(기본)**: 고도 낮음→높음을 파랑 → 하늘색 → 연두 → 초록 → 주황 → 빨강으로
  칠하는 스크린골프식 등고 팔레트. 하단에 범례 막대 표시.
- **경사**: 기존 게이트 4 팔레트(완만=녹색, 급경사=빨강). 궤적-경사 방향 육안 점검용.

`GreenColorMode`로 관리하며 색만 바뀌고 지형·물리는 동일하다.

## 육안 메모

- 기본 카메라에서는 궤적 라인이 얇아 직선처럼 보일 수 있다. SceneKit 드래그로 시점을 돌리면 측방 브레이크가 더 잘 보인다.
- 급경사 그린(`2_06_4`)은 우측에 주황 경사 띠가 뚜렷하고, β=−9°와 함께 홀 진입(holeIn)이 확인됐다.
- 완화 문구는 export CSV의 `status` 열과 앱 하단 상태 텍스트로 확인 가능.
