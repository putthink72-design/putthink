# 게이트6 실경로 승격 기준 (확정)

섀도 모드 로그가 아래를 **모두** 만족하면 승격 검토 대상.

## 표본

- 전체 표본 합계 ≥ **100건**
- 볼 ≥ **40**, 홀 ≥ **40** (나머지는 혼합 가능)
- **3곳 이상** 서로 다른 실외 잔디 장소

## 정확도 (장소마다 개별 충족)

- 볼: 수동 지정 대비 `|delta_m|` 의 **P90 ≤ 3 cm**
- 홀: 수동 지정 대비 `|delta_m|` 의 **P90 ≤ 2 cm**
- 한 장소 데이터로 전체 평균을 끌어올리는 일반화 금지

## 오탐

- 정의: `오탐율 = false_positive_rejected 건수 / 자동 검출 시도 총 횟수`
- 분모 = RGB 후보가 생성된 **자동 검출 시도(CSV 행)** 수
- 수동 지정은 ground truth이며 분모에 포함하지 않음
- 장소마다 **오탐율 < 5%**

## 도구

```bash
python3 Scripts/analyze_gate6_promotion.py FieldData/outdoor-pull -o Docs/gate6_promotion_report.md
```

## 승격 시 UX (기준 충족 후)

- 설정에 「자동 인식 사용」 토글, 기본 OFF
- 켠 상태에서도 탭으로 수동 재지정 가능
- confidence 미달 프레임은 수동 안내
- 승격 후에도 섀도 로깅(수동 대비) 유지

기준 미달 시 수치를 낮춰 승격하지 않음.
